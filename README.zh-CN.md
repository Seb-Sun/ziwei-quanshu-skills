# 紫微斗数全书研读技能

[English](README.md)

面向 ChatGPT 与 DeepSeek 的提示词和可携带技能协议，用于依据用户提供的《紫微斗數全書》版本研读原书、核验格局条件及解释命盘。

**公开版不附书。** 本项目只提供执行指令、工作流程和自行整理的方法释义，不分发原书PDF、扫描页、全书转录或个人命盘记录。使用者需自行提供合法取得的相关资料。

## 核心功能

- 把条件分成“满足、不满足、未知”，未提供不能当成不存在。
- 区分基本组合与完整成格，不省略生年、宫位、庙陷、煞忌和例外。
- 分开本命、大限、小限、流年，不把不同时间层的星曜混用。
- 先讲有依据的具体判断，再讲原因和可能表现，不以反复说“不一定”替代分析。
- 每次回答以“直白总结”收尾。
- 保留书内歧义，不自创分数、概率、条件数量或缺失算法。

这是一套传统文献研读与解释协议，不是已经验证的现实预测系统，也没有内置完整排盘引擎。

## 使用方法

1. 选择一个版本，打开对应的 `PROMPT.md`。
2. 将分隔线后的正文粘贴到新对话。
3. 提供自己合法取得的原书相关页面或文字，注明书名、版本及页码口径。先给与问题有关的部分即可。
4. 如需解释命盘，提供可核实的已有盘；字段可参考该版本的 `references/input-schema.md`。不必提供无关的出生隐私。
5. 提出具体问题。助手必须说明实际读到了什么，再使用依赖原文的规则。

若宿主明确支持 `SKILL.md`，按该宿主的方式加载所选完整目录。普通聊天中，上传文件夹或ZIP不等于全部资料已经被读取；图片、检索、文件和代码能力均以当前环境为准。

没有原书资料时，可以解释随包的方法释义或整理待核问题；不能声称已核原书，也不能把释义当作完整规则库进行扩展占断。

## 版本与页码

方法释义参考的是1989年出版的《紫微斗數全書》版本，版本信息列原著陳希夷、校編梁湘潤、发行台灣文源書局有限公司。整理时使用的扫描件共334页，PDF页码从封面计起。

释义中的页码只是该扫描件的定位信息，不能直接用于所有版本。使用其他副本时先建立对应关系；只有实际读取用户提供的页面后，才能说本轮完成原文核验。释义不是全书替代品，也不是逐字校定本。

本项目没有固化任何人的命盘、起限年龄或争议排法。用户指定的排法应记作采用口径，不冒充已经由原书唯一证明的规则。
