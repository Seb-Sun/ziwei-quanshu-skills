# 命盘资料与输出协议

以下字段是执行约定，不是原书排盘术语的新增学说。用户可给清晰盘图或文本，不必强填全部字段；按问题只索取必要项。

## 已有命盘优先

```yaml
问题: 希望分析的主题或核对的格局
回答文字: 简体或繁体
资料来源: 排盘工具名称、版本或人工盘，未知可写未知
采用规则: 闰月、时辰、历法、年龄和四化口径；不明写未知
出生信息:
  原始日期: "原样保留"
  历法: 公历或农历或未知
  是否闰月: 未知
  出生时间及精度: 未知
  出生地和当时时区: 未知
  原书男女行限分组所需资料: 未提供
生年干支: 未知
五行局: 未知
命宫: 未知
身宫: 未知
十二宫: [] # 每宫记录宫名、地支、宫干如已知、星曜、庙陷、四化、资料位置
会照夹冲: [] # 保留明确的关系、涉及宫位、星曜及资料来源
四化: [] # 每条记录星、化名、宫、时层及采用表
大限: null # 起止年龄/年份、顺逆、宫位、星曜、起限与年龄口径
小限: null
流年: null # 目标年份、太岁宫、流曜与四化；不可用小限替代太岁
```

出生地和时区用于解释现有记录及有工具时的历法换算，不自动授权真太阳时校正。已给可靠命盘且不需重排时，不必索取与问题无关的出生隐私。若要校盘，核实命身、宫位、主星位置、四化、五行局和运限口径；盘不全时说明局部可读范围。

## 证据表

| 规则与书页 | 原文条件 | 命盘事实及来源 | 状态 | 修正与适用范围 |
|---|---|---|---|---|
| Rxx / PDF n | 逐项分列，不省略否定词 | 来自用户盘或经验证的计算 | 满足/不满足/未知 | 煞忌、救解、时层、原文冲突 |

三值含义：满足须有可见证据；不满足须有相反证据；缺字段是未知，**未提及某煞星不等于确认无煞**。格局可标“基本组合存在”“完整条件具备”“条件不具备”“资料不足”；不要把局部符合升级为全部成立。阈值或关系有歧义，单列歧义。

## 默认答复结构

1. 主要判断及资料范围：先说书内证据支持的具体倾向，再简述已确认资料、关键缺项和本轮实际读取的原书页码。
2. 条件核验表：只列与本题有关的规则，附支持及反证。
3. 综合解释：身命基础、格局与修正；专题宫位及三合对宫；有资料才分析运限。每项主要判断按“盘面事实→原书条件及页码→白话含义→有依据的可能表现或结果→改变判断的条件”说明，标明时层。这是书内解释顺序，不是现实因果机制。
4. 不能确定的部分和必要补充：给最少的下一步资料清单。
5. 直白总结：用普通中文直接回答本题，覆盖主要结论、关键依据、方案或时期的差别、共同结论和仍不能确定的事项；按本题取舍，不机械填满。让用户只读总结也能理解正文。保留重要条件，不新增判断或提高结论的确定性。简短术语问答也须用一两句话收束。

正文先回答用户最关心的问题，再解释依据；必要术语首次出现时附白话解释。不要用星曜、宫位名称堆砌结论，或只用“有支持、有修正”“无法保证”等模糊说法。涉及考试与毕业时，说明书内依据能判断到哪一步、是否足以区分通过、补考、延毕等现实结果，不把缺少对应规则的结果自行补写。

不确定性应指出具体缺项、歧义及受影响的结论，不在每段重复“不能保证”。部分条件成立时，仍解释已成立部分的含义。总结先归纳主要倾向、原因和有依据的可能表现，再说明关键未知。现代类比明确标作理解例子，不能冒充原书规则或未来事件；不为具体而虚构性格及生活情节，也不为明确而掩盖规则冲突。

只需输出简明证据、条件与结论依据，不要求展示隐含思维链。用户问术语时可直接解释；缺盘不妨碍做书内知识问答。传统解释与现代生活建议分开标注，后者不能假称是原书断语。健康、财务、法律等实际决定应依据相应现实证据和专业判断；不把星盘解释当作事实预测。
